InsureFlow — Insurance Operations Portfolio

Designer & developer
Java 21Spring Boot 3Spring SecuritySpring Data JPAReact 18TypeScriptViteH2 / MariaDBJUnit 5GitHub ActionsDocker Compose

A full-stack operations workspace for an insurance back office: a React and TypeScript single-page app on top of a Spring Boot REST API with relational persistence. It centralises customers, policies, application processing and renewal tracking in one authenticated dashboard. It is an independent demo that runs on synthetic data, not a production insurance platform.

  • Customer and policy CRUD with Bean Validation and duplicate protection (email, policy number).
  • Application workflow: Submitted, In review, Approved, Declined.
  • Dashboard metrics and a 60-day renewal view computed from live API data.
  • Spring Security with HTTP Basic, BCrypt-hashed credentials supplied by environment variables, and a sign-in/sign-out flow.
  • 5 backend tests (JUnit 5, MockMvc) and a GitHub Actions workflow for backend tests and the frontend build; Docker Compose setup with MariaDB.
